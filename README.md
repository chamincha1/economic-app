# MARKET PULSE — 국내 주식시장 변동성 분석 및 급변 시점 자동 탐지 프로그램

**고등학교 파이썬 수행평가용 데이터 분석 웹앱**. 실제 주식 가격 분석, CSV 업로드, 인터넷 없이 실행 가능한 가상 데이터 시연을 지원합니다.

> **1단계 개선판 (2026-11-11)**: 실제 국내 주식 일별 OHLCV 수집을 기본으로 설정했습니다. 수집 실패 시 NAVER → KRX 순으로 시도하며, 이전 캐시가 있으면 **이전 데이터임을 명시**합니다. 이 패키지에는 실제 주가 시계열을 미리 넣어 두지 않았습니다. 사용자의 PC가 데이터 제공처에 접속하면 실제 데이터가 `data_cache/`에 생성됩니다. 실시간 체결가 API는 아직 연결하지 않았습니다.

## 1. Windows에서 가장 쉽게 실행하기

1. 압축파일을 **압축 해제**합니다.
2. PC에 **Python 3.10 이상**이 설치되어 있는지 확인합니다. (권장 Python 3.11 또는 3.12)
3. `실행하기_윈도우.bat`을 더블클릭합니다.
4. 첫 실행 때 필요한 라이브러리를 자동으로 설치합니다. **인터넷이 필요**합니다.
5. 잠시 후 웹브라우저에 보통 `http://localhost:8501` 주소로 열립니다. 브라우저가 자동으로 열리지 않으면 주소를 직접 입력하세요.
6. 프로그램 사용을 종료하려면 검은색 터미널 창에서 **Ctrl+C**를 누릅니다.

⚠️ 프로그램은 사용자의 컴퓨터에서만 실행되는 로컬 웹앱입니다. 설치 후 가상 데이터로 테스트할 때는 인터넷이 필요하지 않습니다. 실제 주가 수집에는 인터넷이 필요합니다.

## 2. 실제 주가 6개 기업의 과거 데이터를 미리 수집하기 (추가된 기능)

**가장 쉬운 방법**: Windows에서 `실제주가_수집하기_윈도우.bat`을 더블클릭하세요. 기본적으로 실행 날짜를 기준으로 최근 약 3년의 삼성전자, SK하이닉스, 현대자동차, 기아, NAVER, 카카오 시세를 가져옵니다. 성공하면 `data_cache/005930.csv`와 `data_cache/005930.meta.json`처럼 파일이 각각 저장됩니다. **외부 제공처가 응답해야만 실제 데이터 파일이 생성됩니다.**

VSCode/터미널에서 직접 수집하려면 다음을 실행하세요.

```bash
python -m pip install -r requirements.txt
python collect_real_data.py
```

기간 또는 종목을 변경할 수도 있습니다.

```bash
python collect_real_data.py --start 2024-01-01 --end 2026-11-11 --only 005930 000660
```

화면에서는 **실데이터 모드가 기본**이고, 데이터 수집이 성공한 경우 데이터 출처, 마지막 거래일, 수집 시각이 표시됩니다. 오프라인 등으로 실패하면 마지막으로 저장된 CSV를 사용하는데, **최신 자료로 표시하지 않습니다.** 이전 저장 데이터가 없으면 오류를 표시하며, 가상 데이터로 몰래 대체하지 않습니다. 가상 데이터를 사용하려면 사용자가 직접 예시 데이터 모드를 선택해야 합니다.

**알아둘 점**: FinanceDataReader는 외부 제공처에 의존하므로 일부 시점에 연결이 실패할 수 있습니다. 제공처 간 데이터 조정 방식·기업행동 반영 방식·KRX/NXT 시장 기준 등에 차이가 있을 수 있습니다. 공인된 실시간 호가·주문 시스템이 아닙니다. 다운로드한 CSV의 데이터는 프로그램을 실행해 확인하세요.

## 3. VSCode / 터미널에서 실행하기

프로젝트 폴더로 이동한 터미널에서 다음을 차례대로 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

`python` 명령이 실행되지 않으면 Windows에서는 `py -3`, macOS/Linux에서는 `python3`를 이용해 보세요.

## 4. Google Colab에서 실행할 수 있나요?

이 프로그램은 **Streamlit 웹앱**이라 기본적으로 PC의 터미널 또는 Streamlit을 배포한 서버에서 실행하도록 설계했습니다. Colab 노트북에서 `app.py`를 셀에 붙여넣는 방식으로 즉시 실행되지는 않습니다. 수행평가에서 Colab 제출이 필수라면 별도 Colab 분석 노트북을 제작해 제출하는 방식을 권장합니다.

## 5. 화면 사용법

왼쪽 설정에서 데이터 모드를 선택합니다.

- **예시 데이터**: 보조 모드. 인터넷 없이 가상기업 A~D 분석 기능 테스트. 값은 **가상 데이터**이며 실제 주가가 아닙니다.
- **국내 주식 실데이터**: 기본 모드. 삼성전자, SK하이닉스, 현대자동차, 기아, NAVER, 카카오 중에서 선택. FinanceDataReader를 통해 과거 주가를 수집합니다. 온라인 데이터는 제공처나 인터넷 상태에 따라 수집이 안 될 수 있습니다. 한 번 수집한 자료는 `data_cache` 폴더에 저장되어 오류 발생 시 이전 저장 데이터로 분석할 수 있습니다. 화면에 출처가 구분됩니다.
- **CSV 직접 업로드**: 날짜, 종가, 거래량 열이 있는 1개 이상의 CSV를 업로드합니다. `Date,Close,Volume` 또는 `날짜,종가,거래량` 등의 이름을 지원하며 UTF-8·CP949도 허용합니다. 시작일보다 충분히 앞선 거래일을 포함하세요.

분석 기간과 `비교 기간(거래일)`, `Z 기준`, `거래량 급증 배율`을 변경하고, **대시보드 / 종목 상세 / 급변 탐지 내역 / 검증·사용법** 탭을 확인하세요. 각 결과는 CSV로 저장할 수 있습니다.

## 6. 사용한 통계 원리

- 일일 수익률(%) = `(오늘 종가 / 전날 종가 - 1) × 100`
- 20일 변동성 = 당일 포함 최근 20개 일일 수익률의 **표본 표준편차** (연율화하지 않음, 단위 %포인트)
- 가격 급변 = `|당일 수익률 - 직전 20일 평균 수익률| / 직전 20일 수익률 표준편차 ≥ Z 기준`
- 거래량 급증 = `당일 거래량 / 직전 20거래일 평균 거래량 ≥ 거래량 기준`
- MDD(%) = 분석 기간에서 날짜별 누적 최고 종가 대비 하락률 중 가장 낮은 값

**오늘을 평가하는 과거 기준에 오늘 데이터는 포함하지 않습니다.** 과거 표준편차나 거래량이 0일 때 0으로 나누지 않고 별도의 변화 판정 규칙을 적용합니다.

## 7. 수행평가 테스트

`tests/test_stock_core.py`와 `tests/test_market_data.py`에 자동 검증 테스트가 포함되어 있습니다. 실제 API 접속 여부는 사용자의 인터넷 연결에서 별도로 확인해야 합니다. 다음 명령으로 실행합니다.

```bash
python -m pip install pytest
python -m pytest -q
```

테스트에는 날짜 중복 및 잘못된 가격 제거, 계산 규칙 검증, 급등/급락 및 거래량 변화, 기준 계산의 미래 정보 누출 방지, 분석 기간 오류, CSV 입력 등이 포함됩니다.

## 8. 참고 및 제한 사항

- 이 프로젝트는 **과거 금융 데이터의 통계적 특징 탐구**에 목적이 있습니다. 매매 추천, 투자 자문, 미래 가격 예측이 아닙니다.
- 기업별 주가 비교는 같은 거래일을 기준으로 합니다. 상장 날짜·거래정지 등으로 공통 거래일이 적다면 비교할 때 주의가 필요합니다.
- **액면분할·주식병합·권리락·배당** 등에 따라 원시 종가 변화가 왜곡될 수 있으므로, 탐지 결과를 이상 사건의 확정 판정으로 해석하면 안 됩니다.
- 종목 데이터 제공 업체의 페이지 구성이나 정책 변화로 데이터 조회가 안 될 수 있습니다. 그 경우 저장된 CSV 또는 사용자 CSV 모드로 분석할 수 있습니다.
- 샘플 자료는 실제 기업의 거래 이력을 재현한 것이 아니라 컴퓨터가 생성한 완전한 **가상 데이터**입니다.

## 9. 파일 구성

```text
MarketPulse_KR/
├── app.py                  # 실제 사용자 화면 (Streamlit)
├── stock_core.py           # 데이터 정리, 통계, 급변 탐지 알고리즘
├── market_data.py          # 실데이터 수집·검증 및 출처/캐시 관리
├── collect_real_data.py    # 6개 기업 실제 과거 데이터 일괄 수집
├── requirements.txt        # 필요한 Python 패키지
├── 실행하기_윈도우.bat       # Windows 앱 실행
├── 실제주가_수집하기_윈도우.bat # Windows 실제 주가 수집
├── run_mac_linux.sh        # macOS/Linux 실행
├── sample_data/            # 인터넷 없이 업로드 가능한 가상 데이터 CSV
├── data_cache/             # 실데이터를 처음 수집하면 자동 생성
├── tests/test_stock_core.py # 분석 자동 테스트
├── tests/test_market_data.py # 수집·캐시 자동 테스트
└── README.md               # 실행 및 제출 안내
```
