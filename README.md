# MARKET PULSE 2.1 — 실제 주가 자동 조회 + 관심종목 복구

**중요:** MARKET PULSE는 **CSV 파일 없이** 인터넷으로 실제 한국 주식의 과거 일별 OHLCV(일봉)를 자동 가져옵니다. **실시간 체결가가 아니며**, 실제 거래일·제공처·수집 시각을 확인해야 합니다. 새 설치에서 인터넷 접근이 불가능하면 가격을 만들어 표시하지 않습니다.

## 실행 (Windows · VSCode)

1. 이 ZIP을 **새로운 폴더에 압축 해제**합니다. `index.html`, `app_server.py`, `src` 폴더가 같은 프로젝트 최상위에 있어야 합니다.
2. VSCode의 **파일 → 폴더 열기**에서 압축을 푼 폴더를 선택합니다.
3. VSCode 터미널에서 아래 순서대로 실행합니다.

```powershell
python -m pip install -r requirements.txt
python app_server.py
```

4. Chrome에서 **http://127.0.0.1:8765**를 엽니다. 또는 `실행하기_윈도우.bat`를 더블클릭해도 됩니다.
5. 홈에 기본 관심종목 **삼성전자·SK하이닉스·현대자동차·기아·NAVER·카카오 6개**가 뜨고 **실제 과거 일봉 데이터 조회가 자동으로 시작**됩니다. **CSV 입력이나 API 키가 필요하지 않습니다.** 첫 온라인 조회는 제공처 응답 속도에 따라 시간이 걸릴 수 있습니다.

## 관심종목 추가·삭제

- **왼쪽 남색 사이드바 → 관심종목 → 기업명 또는 6자리 코드** 입력창.
- 기본 목록 30개 중 기업명을 2글자 이상 입력하면 목록이 나오고 해당 기업을 클릭해 추가할 수 있습니다. 예: `LG화학`.
- **6자리 국내 주식 종목코드**를 직접 입력해 추가할 수도 있습니다. 예: `051910`.
- 목록에 없는 회사는 **전체 KRX 종목명 검색** 버튼으로 찾아 추가할 수 있습니다. KRX 검색이 실패하면 6자리 종목코드로 입력하세요.
- 왼쪽 관심종목의 **×**를 눌러 제거할 수 있고, `국내 시세 보드`의 각 기업 옆 `+ 추가` 버튼으로도 추가할 수 있습니다.
- 관심종목은 **현재 브라우저의 로컬 저장소**에 저장되어 같은 주소로 다시 접속하면 유지됩니다. 브라우저 데이터 삭제나 다른 브라우저 사용 시 목록은 공유되지 않습니다.
- 최대 12개까지 추가 가능. 화면 진입 시 처음 8개 종목은 자동 조회하고, 나머지도 추가 시 자동 조회합니다. 과도한 공급처 호출 방지를 위해 최대 3개씩 동시에 요청합니다.

## 빠른 시세 및 캐시

- **처음 온라인 조회:** FinanceDataReader를 통해 NAVER → KRX 순으로 과거 일별 가격을 조회합니다. `data_cache/` 폴더에 실제 가격·출처 메타데이터를 저장합니다.
- **재실행:** 이전에 저장된 **실제 일봉을 먼저 빠르게 표시**한 다음 온라인에서 갱신합니다. 이전 자료는 `저장된 데이터/최신 아님`으로 명시합니다.
- **서버 메모리 캐시:** 새로 조회한 가격은 15분간 재사용하며, 강제 새로고침 버튼을 누르면 다시 시도합니다.
- **실제 데이터 제공 실패:** 가짜 가격을 만들지 않습니다. 해당 종목에 오류 메시지를 보이고, 실제 저장 이력이 있는 경우만 이전 데이터를 표시합니다.
- **당일 주가 주의:** 일봉 수집기는 장중 실시간 체결가가 아닙니다. 네이버 증권의 장중 표시값과 일치하지 않을 수 있고, 제공처의 일봉 갱신이 지연될 수 있습니다.
- 이전에 다운로드해 둔 **실제 주가 캐시**가 있다면 기존 프로젝트의 `data_cache/*.csv`와 `*.meta.json`을 새 폴더의 `data_cache/`로 복사할 수 있습니다. 출처가 불분명한 가상 데이터는 복사하지 마세요.

## 뉴스 URL · GroqCloud AI (선택)

주가 조회에는 AI API 키가 필요하지 않습니다. 뉴스 링크의 AI 분석이 필요하다면 `.env.example`을 복사하여 **`.env`**로 이름을 바꾸고 새 **GroqCloud** 키를 입력합니다.

```dotenv
GROQ_API_KEY=실제_GroqCloud_API키
GROQ_MODEL=openai/gpt-oss-120b
GROQ_DAILY_REQUEST_CAP=24
```

`GROQ_API_KEY`는 **GitHub에 올리지 마세요.** `.gitignore`에 `.env`가 포함되어 있습니다. 앱은 뉴스 분석 버튼을 눌렀을 때만 AI를 호출하고, 호출량 제한을 둡니다. 이 제한은 공급사 과금 보증이 아니므로 GroqCloud 요금제와 사용 한도를 별도로 확인하세요.

## 기능 구분

| 기능 | 상태 |
|---|---|
| 온라인 실주가 자동 조회 | 홈 첫 실행 시 기본 6개 자동 요청 · CSV 불필요 |
| 종목 검색·추가·삭제 | 사이드바 및 국내 시세 보드 · 30개 기본 목록 + 6자리 코드 |
| 주가 분석/차트/급변탐지 | 수집된 실제 과거 일봉 기준 |
| GroqCloud 기사 링크 분석 | `.env`에 키가 설정된 경우 버튼을 눌러 호출 |
| AI 방향성 예측 | 로컬 Python 기존 모델 사용 · 버튼을 눌렀을 때 계산 |
| CSV 업로드 | **선택 사항** · 데이터 센터에서 사용 |
| Google AI Studio/Node/npm/LM Studio | **전혀 필요하지 않음** |
