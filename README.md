# MARKET PULSE 2.0 — Google AI Studio 없이 실행하는 고속 버전

기존 Google AI Studio용 화면의 **남색 사이드바 / 밝은 카드 / 민트색 강조 / 8개 메뉴**를 그대로 유지했습니다. Python으로 실행하는 로컬 HTTP 서버가 실제 일봉, CSV, 모델 예측, 공개 기사 URL과 GroqCloud API를 연결합니다. **Google AI Studio, Node.js, npm, Streamlit은 필요하지 않습니다.**

## 시작 (Windows)

1. ZIP 압축을 풉니다.
2. 첫 실행은 `실행하기_윈도우.bat`를 더블 클릭합니다. 자동으로 필요한 Python 라이브러리를 설치할 수 있으므로 인터넷 연결이 필요합니다.
3. 브라우저에서 `http://127.0.0.1:8765` 접속합니다. 서버 창을 닫으면 앱도 종료됩니다.
4. GroqCloud 기사 분석까지 사용하려면 `.env.example` 파일을 복사해서 `.env`로 저장하고 **새로 발급받아 비공개로 보관 중인** `GROQ_API_KEY`를 입력합니다. 노출·폐기했던 키는 재사용하지 마세요.

또는 터미널:

```powershell
python -m pip install -r requirements.txt
python app_server.py
```

## 기능

| 화면 | 데이터와 역할 |
|---|---|
| 홈 | 30개 카탈로그에서 처음 3개 종목만 **순차로 조회**. 차트·값은 실제 수집된 데이터에서만 표시 |
| 국내 시세 보드 | 30개 회사 검색·필터, 클릭 시 해당 종목 과거 일봉 요청 |
| 종목 상세 | 실제 일별 종가 차트, 등락률, 이동평균, 변동성, 52주 범위 |
| 급변 탐지 | 과거 20거래일 기준 수익률 Z 점수로 이상 변동 표시 |
| 뉴스·공시 | 공개 뉴스 URL을 1~4개 입력해 서버에서 HTML 본문을 추출하고 GroqCloud로 정성 분석 |
| AI 예측 | 기존 scikit-learn 시계열 모델을 **버튼 클릭 시에만** 실행 |
| 백테스트 | 앞 단계의 시험 구간 성능 표를 표시. 가짜 성능 없음 |
| 데이터 센터 | 조회 출처와 마지막 거래일, CSV 파일 수동 업로드 |

## 속도 최적화

- 화면 변경 때마다 Python 분석 코드를 다시 실행하지 않는 SPA 형태. UI 스타일과 레이아웃은 기존 디자인 그대로 유지.
- 주가 데이터는 서버 **15분 TTL**에 캐시, 클라이언트에 분석된 결과 캐시. 강제 갱신 버튼 제공.
- 초기 3개 종목만 순차 조회; 카탈로그 30종목에 대한 무조건 일괄 네트워크 요청 금지.
- 차트 브라우저 표시에는 최대 약 300개의 실측 점만 사용(값 생성·보간 없음).
- 머신러닝은 버튼을 눌러야 실행. 기사 HTML 추출·GroqCloud 요청도 버튼 클릭 시에만 수행.
- GroqCloud는 Python 표준 라이브러리의 HTTP 요청 사용. Streamlit/Node/npm/LangChain 및 관련 xxhash 의존성 미사용.
- 서버는 **127.0.0.1에만 바인딩**되어 내부망에 공개되지 않습니다. `.env`는 HTTP 파일로 제공하지 않습니다.

## 기사 분석 품질 설정

기본 모델: `openai/gpt-oss-120b`. 화면에서 **심층 분석** 선택 시 첫 분석과 근거·과장 점검을 위한 수정 분석 **2회 호출**, **일반 분석**은 1회 호출합니다. AI가 원문 외 사실을 검증했다고 주장하지 않습니다. 기사 외부 진위는 별도 확인이 필요하며, 주가 상승/하락 확률을 임의로 생성하지 않습니다.

**GroqCloud Free 요금제는 사용량 제한이 있습니다.** 이 앱은 HTTP 429 시 자동 유료 전환이나 반복 재시도를 하지 않습니다. 기본적으로 하루 24회 AI 요청 제한(심층 분석 1회 = 2회 API 요청)을 둡니다. 이는 앱 내부 보호 장치이며 제공사의 과금/무료 한도를 보장하지는 않습니다. 계정 요금제에 유료 청구가 활성화되어 있지 않은지 사용자가 확인해야 합니다.

## 데이터 시점 / 보안

- FinanceDataReader 주가는 **일봉 역사 데이터**로 실시간 체결가가 아닙니다. 화면에 원출처·마지막 거래일 표시. 실패 시 이전 저장 캐시만 사용하면 따로 표시합니다.
- 실제 제공처의 제공 지연이 있을 수 있습니다. 데이터가 없을 때 값이나 뉴스를 생성하지 않습니다.
- 기사 수집은 일반 공개 웹페이지만 지원. 로그인/유료 기사 우회 불가. 내부망 URL 차단.
- AI API 키는 `.env` 또는 OS 환경 변수만 사용하며 브라우저에 보내지 않습니다.
- 투자 결정·매매 추천 서비스가 아닙니다.

## 제거한 Google AI Studio 전용 파일

`package.json`, `package-lock.json`, `server.mjs`, `tests_web/`, AI Studio 실행 복구 보고서 및 npm/Vite 관련 파일을 제거했습니다. **화면을 구성하는 HTML/CSS/JS는 실제 앱의 핵심이므로 유지**했습니다.

## 자동 테스트

```powershell
python -m unittest discover -s tests -v
```

테스트는 외부 주식/AI 서비스 없이 동작하도록 stub/mocking합니다. 실제 시세 및 GroqCloud 서버의 연결·사용량·권한은 사용자 환경에서 확인해야 합니다.
